# 🖧 RDSII-Server

Exemplo de comunicação `cliente-servidor` utilizando `sockets TCP` em `Python`.

O projeto demonstra, de forma simples, como estabelecer uma conexão entre um cliente e um servidor através do protocolo TCP, permitindo o envio e recebimento de mensagens pela rede.

O servidor aguarda uma conexão na porta 8000, recebe uma mensagem enviada pelo cliente.


## 📄 Sobre o Projeto
Atividade desenvolvida com o objetivo de demonstrar os fundamentos da comunicação em rede utilizando Python, sockets e protocolo TCP.
